# references/

Сюди переносяться файли компонентів, перелічені в таблиці `SKILL.md`
(`button.md`, `badge.md`, `card/default.md` тощо).

Кожен новий компонент додається за шаблоном:

```
## Node
(Figma node id / canvas)

## Props
(variant / size / state)

## Tokens
(кольори, шрифти, ефекти — тільки токени ДС)

## Notes
(макс. 1-3 нюанси)
```

Після додавання файлу — додай рядок у таблицю компонентів у `SKILL.md`.
