# references/tokens/

Каталог токенів з Token Studio (Figma Tokens), використаних для генерації
змінних у компонентах Wanda Design System. Джерело істини для назв токенів —
щоб не вгадувати/реверсити їх з Figma-нод (як було з чипс-gap токеном раніше).

## Статус

Наповнюється порціями від власника репо. Поки що порожньо.

## Структура

Один файл на категорію токен-сету (як їх поділено в самій Token Studio),
наприклад:

```
color.md       — семантичні кольори (bg/fg/border/stroke тощо)
spacing.md     — відступи, gap, padding scale
radius.md      — border-radius scale
typography.md  — font family/size/weight/line-height (якщо не покрито references/typography.md)
effects.md     — shadow/glow/bevel значення (якщо не покрито references/effects.md)
```

Категорії уточнюються по мірі надходження даних — не фіксовані наперед.

## Формат запису токена

```
## <Назва токен-сету>.<токен>

- **Значення / alias:** ...
- **Використовується в:** (компонент(и) з таблиці SKILL.md, якщо відомо)
- **Нотатки:** (макс 1-3 нюанси)
```

## Після наповнення

Додати рядок у таблицю Figma-файлів/технічних нюансів у `SKILL.md`, якщо
з'явиться окремий Token Studio файл-джерело (назва, key/посилання).
